# How to use:
### 1) Download/clone repo file to web server with php
### 2) Download images.zip from Releases
### 3) Extract images.zip to website folder
### 4) Create a separate databse for website in your mysql server
### 5) Load .sql file from aowow_turtle_sql.zip in Releases into that new database
### 6) Edit config.php to point to your turtle world, logon, and website db
